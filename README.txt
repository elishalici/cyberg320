ПАРОВОЗИК КОТОРЫЙ СМОГ — интерактивная миссия

Содержимое:
- index.html — сайт
- assets/ — фотографии, используемые на экранах

Локальный просмотр:
Откройте index.html в браузере. Все изображения подключаются из папки assets.

Публикация:
Можно разместить файлы на GitHub Pages. В репозитории должен лежать index.html в корне и папка assets рядом.
Документация GitHub Pages: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

Важно:
Перед публичной публикацией проверьте фотографии и персональные данные на изображениях, особенно номера автомобиля.
